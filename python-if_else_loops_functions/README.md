# Python - if/else, loops, functions

This project contains Python scripts that practice conditions, loops and functions.

## Files

| File | Description |
|------|-------------|
| `0-positive_or_negative.py` | Assigns a random signed number to `number` and prints whether it is positive, zero or negative |

## Requirements

- Python 3
- Ubuntu 20.04 LTS (or any Linux system)
- Files end with a new line
- Scripts are executable

## Usage

    chmod +x 0-positive_or_negative.py
    ./0-positive_or_negative.py

## Example output

    -4 is negative
    0 is zero
    7 is positive
