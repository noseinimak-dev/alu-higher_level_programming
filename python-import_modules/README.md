# Python - Import & Modules

This project contains a Python program that imports a function from another file.

## Files

| File | Description |
|------|-------------|
| `add_0.py` | Defines the function `add(a, b)` that returns the sum of two integers |
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |

## Requirements

- Python 3
- Ubuntu 20.04 LTS (or any Linux system)
- Files end with a new line
- Scripts are executable

## Usage

    chmod +x 0-add.py
    ./0-add.py

## Example output

    1 + 2 = 3
