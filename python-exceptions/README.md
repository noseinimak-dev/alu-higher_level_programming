# Python - Exceptions

This directory contains tasks from the alu-higher_level_programming project on handling and raising exceptions in Python.

## Requirements

- Python 3 (tested on Ubuntu)
- All files start with `#!/usr/bin/python3`
- Code follows the pycodestyle style
- All files are executable
- No modules are imported

## Files

| File | Description |
|------|-------------|
| `0-safe_print_list.py` | Prints x elements of a list and returns the number printed |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()`, returns True or False |
| `2-safe_print_list_integers.py` | Prints only the integers among the first x elements |
| `3-safe_print_division.py` | Divides two integers and prints the result in `finally` |
| `4-list_division.py` | Divides two lists element by element, handling errors |
| `5-raise_exception.py` | Raises a TypeError |
| `6-raise_exception_msg.py` | Raises a NameError with a message |
