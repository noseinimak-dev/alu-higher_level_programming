# python-everything_is_object

This directory contains answers and scripts that explore how Python treats everything as an object: identity versus equality, mutable versus immutable types, and how arguments are passed to functions.

## Requirements

- Python 3 (interpreter `/usr/bin/python3`)
- Answer files contain only the answer, on a single line
- `19-copy_list.py` starts with `#!/usr/bin/python3`, is executable, and is 3 lines long
- No modules are imported

## Files

| File | Description |
|------|-------------|
| `0-answer.txt` | Function that prints the type of an object |
| `1-answer.txt` | Function that returns the identifier of an object |
| `2-answer.txt` to `5-answer.txt` | Whether two integer variables point to the same object |
| `6-answer.txt` to `9-answer.txt` | Equality and identity with strings |
| `10-answer.txt` to `13-answer.txt` | Equality and identity with lists |
| `14-answer.txt`, `15-answer.txt` | List aliasing, `append` and `+` |
| `16-answer.txt` to `18-answer.txt` | Passing integers and lists to functions |
| `19-copy_list.py` | Function that returns a copy of a list |
| `20-answer.txt` to `23-answer.txt` | Whether an expression is a tuple |
| `24-answer.txt` to `26-answer.txt` | Identity with tuples and integers |
| `27-answer.txt`, `28-answer.txt` | Whether the `id` of a list changes with `+` and `+=` |
